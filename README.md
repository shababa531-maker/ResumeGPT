# ResumeGPT

An AI-powered Resume Builder that helps users create ATS-friendly resumes with AI-generated content, live preview, and PDF export.

## link
    https://resumepro-ai.vercel.app/

##  Features
 AI Resume Generation
 ATS-Friendly Templates
 Live Preview
 PDF Download
 Multiple Themes
 Authentication
 Responsive Design

##  Tech Stack
 React.js
 Tailwind CSS
 OpenAI/Gemini API

##  Git Installation
git clone https://github.com/shababa531-maker/ResumeGPT.git

cd ResumeGPT
npm install
npm run dev
